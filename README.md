  Como meu trabalho principal é desenvolvido em repositórios privados, aqui está um resumo das minhas responsabilidades e projetos (sem expor dados confidenciais):

  ### ** Projeto CEUA **
  * **Descrição:** Desenvolvimento do zero e manutenção de um CEUA (Comitê de Ética no Uso de Animais) para análise de projetos submetidos à avaliação, utilizando arquitetura MVC.
  * **Desafio:** Migração de sistema legado (PHP puro) para Laravel 12, garantindo a integridade de todos os registros.
  * **Tecnologias:** `PHP`, `Laravel`, `MySQL`, `jQuery`, `Bootstrap`, `Blade`.

  ### ** Sistema de Gerenciamento de Provas e Usuarios**
  * **Descrição:** Criação de um sistema de geração de provas e usuarios, processando questões e imagens, gerenciando polos, campus e usuarios.
  * **Desafio:** Otimização de consultas complexas no PostgreSQL para reduzir o tempo de resposta e montagem das provas.
  * **Tecnologias:** `Node.js`, `PostgreSQL`, `Docker`, `Tailwind` (no painel admin).
